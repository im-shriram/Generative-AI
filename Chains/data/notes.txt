Transformers are neural network architectures built primarily around attention mechanisms rather than recurrence or convolution. They were introduced in the paper Attention Is All You Need for sequence-to-sequence tasks like machine translation. The original design has an encoder that reads the input sequence and a decoder that generates the output sequence. Self-attention lets each token in a sequence weigh the importance of every other token when building its representation. Multi-head attention runs several attention operations in parallel so the model can capture different relationships. Positional encodings add information about token order because attention alone has no inherent sense of sequence. Each encoder layer typically contains a self-attention sublayer followed by a feed-forward network. Residual connections and layer normalization help stabilize and speed up training in deep stacks. The decoder layer includes masked self-attention so predictions cannot see future tokens during generation. It also includes cross-attention, which lets the decoder focus on relevant parts of the encoder output. Feed-forward networks inside each layer transform each position independently, adding nonlinear processing. Stacking many identical layers gives Transformers great depth and expressive power. Encoder-only variants like BERT are good for understanding tasks such as classification and question answering. Decoder-only variants like GPT are good for autoregressive text generation and in-context learning. Encoder-decoder variants like T5 suit translation, summarization, and other sequence-to-sequence problems.
